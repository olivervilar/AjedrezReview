How to get a Gemini API Key

To use the AI analysis feature, you need a free API key from Google.

  1. Go to Google AI Studio.
  2. Sign in with your Google Account.
  3. Click on the "Get API key" button.
  4. Create a new key or copy an existing one.
  5. Paste it in the input field on this page.
